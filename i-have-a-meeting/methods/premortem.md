# Premortem

**Use when:** fix passes loop and checks, before `done`.

**Move:** Assume presentation just failed on this path. In 2 minutes write 3 concrete reasons (other data, browser, cold start, role, sibling button). Run cheapest check for likeliest.

**Done when:** top reason checked and passing, or listed under paths to avoid.

**Trap:** asking "will it work?" instead of "why did it fail?". First invites confirmation.

**Source:** Gary Klein, "Performing a Project Premortem", HBR, 2007 (https://hbr.org/2007/09/performing-a-project-premortem): prospective hindsight raises correct identification of reasons for outcomes by 30%.
