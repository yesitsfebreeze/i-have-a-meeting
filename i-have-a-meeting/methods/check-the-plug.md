# Check the plug

**Use when:** before deep diagnosis, and again when hypothesis that "had to be right" dies.

**Move:** 60 seconds on basic assumptions: right branch, process, port, config file? Service running? Test tool works on known-good case? Start path from its true beginning, not middle.

**Done when:** each assumption checked with output recorded.

**Trap:** trusting tool. Harness on wrong URL or debugger on stale binary gives confident wrong answers.

**Source:** David Agans, *Debugging: The 9 Indispensable Rules*, 2002, rule 7 "Check the Plug": "Question your assumptions, start at the beginning, and test the tool" (rule text via reviewers, e.g. https://dwheeler.com/essays/debugging-agans.html).
